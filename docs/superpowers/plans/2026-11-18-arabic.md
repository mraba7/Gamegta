# Arabic Edition Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Windows app translates English game subtitles to Arabic with the user's chosen AI provider (Best quality / Fastest), and the Samsung TV app shows them right-to-left in a bundled Arabic font.

**Architecture:** Arabic becomes a target language of the existing pipeline. The AI prompt, the engine selection and every Turkish-only helper are keyed on `UserSettings.TargetLanguage`; the TV page decides direction from the text it receives, so the PC-to-TV protocol does not change.

**Tech Stack:** C# / .NET 10 (WPF app, xUnit tests), plain ES5 JavaScript + CSS for the TV page (webOS/Tizen share `tv/webos`), Python packaging script.

**Spec:** `docs/superpowers/specs/2026-11-18-arabic-design.md`

## Global Constraints

- Keep `// SPDX-License-Identifier: AGPL-3.0-only` on every source file touched or created; never remove a notice in `NOTICE`, `LICENSE`, `THIRD-PARTY-NOTICES.md`.
- With `TargetLanguage == "tr"` behaviour and all existing tests stay byte-for-byte as before.
- Baseline: `GameTranslator.Core.Tests` has 4 pre-existing failures; no new failures anywhere.
- TV page code stays ES5 (no `let`, arrow functions, template strings): Tizen 2019 runs an old Chromium.
- Speaker labels (`NAME:` at line start) are never translated or reordered by our code.
- Build/test commands run from `windows/` with `dotnet` on PATH: `dotnet test tests/<Project> -v q`.

## Review Focus

- Mixed-direction line: a subtitle that starts with a Latin speaker label (`JASON: مرحبا`) must still lay out right-to-left with the label on the right. → Task 5 test `directionOf` + browser check.
- A Turkish user's settings file (no `TargetLanguage`/`AiProvider` keys, `Engine = Gemini`) must keep loading and keep translating to Turkish only if `TargetLanguage` says `tr`; a fresh install defaults to Arabic. → Task 3 tests.
- The model answers in the wrong language or echoes English: the pipeline already hides a translation identical to its source; an Arabic target must not trip Turkish-specific "already in target language" checks. → Task 2 test `ArabicReplyIsKept`.
- AI service down / key rejected in the middle of a game: fall back to Google GTX in Arabic, never to the en-tr Marian model. → Task 4 test.
- Unknown target code in settings (hand-edited file, e.g. `"fr"`): prompt must name a language, never crash; treated as left-to-right. → Task 1 tests.
